A release that turns the board and the mobile monitor into one app, so that the same board works on a PC and a phone, locally or through the ngrok address.

## Changes

- **One board for every screen width.** The board shows the phone screen below 768px and the PC board at 768px and wider. The phone screen hides the **Unanswered questions** band when no question is open, so the task list starts right under the counts.
- **The whole board through the ngrok address.** The address from the QR code now opens the board itself, behind the same 4-digit passcode. Once the passcode is right, you can do what you do on the PC board for up to 12 hours: read every project, switch projects, add, edit, move, archive, and delete tasks and epics, and answer questions. The **Mobile connection** settings and opening a project document in the PC's own application stay on the PC. Anyone who has the address and the passcode gets this access, so keep both private.
- **The first-run guide works on a phone.** The guide runs on the phone screen and through the ngrok address, with full-width buttons.
- **Give the phone address from the command line.** `agboard --project "<name>" remote` prints the ngrok state, the address of that project, and the passcode, and `--json` prints them as JSON. It runs on the PC only and starts nothing.

## Fixes

None.

## Breaking changes

- **The old mobile monitor addresses are gone.** Addresses that end in `/monitor/`, and the monitor's own API, are no longer served and answer with a not-found response. There is no redirect. Scan the current QR code in the PC's **Mobile connection** settings again, and replace saved bookmarks with the new address.

## Required update steps

Update the command, then move the plugin to the same version:

```sh
brew upgrade fooqoo/tap/agboard
agboard update
```

`agboard update` is needed: the Skill changes in this release, and a new agent session asks you to run it until the plugin's version matches the command. On the phone, open the address from the current QR code; old `/monitor/` links no longer work.
