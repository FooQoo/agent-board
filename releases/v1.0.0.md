## English

Agent Board is a local board for sharing tasks, progress, and decisions with Claude Code and Codex. The first public release brings Homebrew installation and guided agent setup to macOS.

This release mixes two stages. The board, tasks, decisions, epics, and the CLI that agents use are generally available (GA). Docs, `connect` and `update`, task listening, the mobile monitor, and the first-run welcome are in public preview, so their behavior may change in a later release. See [Feature stages](https://fooqoo.github.io/agent-board/guide/feature-stages) for what each stage means and the current limits. GA does not mean free of bugs or a promise that nothing will ever change.

### Changes

- **Install with Homebrew.** `brew install fooqoo/tap/agboard` installs a prebuilt, signed command with the web UI included. You do not build Agent Board from source.
- **Connect your agents.** `agboard connect` asks which agents to set up and where, then installs the Skill and the Hook for Claude Code, Codex, or both. It shows every change before it writes, backs up the files it changes, and never overwrites your own edits. (public preview)
- **Keep a Hook quiet where it does not apply.** A Global Hook in a folder that is not bound to a project exits normally with no output, so the agent keeps working.
- **Update the Skill and Hook.** `agboard update` brings installed Skills and Hooks up to the version of your command, and ordinary commands tell you when they are older. (public preview)
- **Answer from your phone.** The mobile monitor connects through ngrok and a passcode. (public preview)

Requires macOS 15 or later on Apple Silicon or Intel. Agent Board itself is MIT-licensed; bundled third-party components keep their own licenses, listed in `THIRD_PARTY_NOTICES.txt`.

### Fixes

This is the first public release, so there are no fixes to an earlier public version.

### Breaking changes

None. There is no earlier public release to break.

### Required update steps

A new installation needs no update steps:

```sh
brew install fooqoo/tap/agboard
cd my-project
agboard project create "My project"
agboard connect
agboard serve
```

For later releases, update the command with `brew upgrade fooqoo/tap/agboard`. When a release changes the Skill or the Hook, run `agboard update`, then review the changed Hook with `/hooks` in your agent. Read the [installation guide](https://fooqoo.github.io/agent-board/guide/getting-started) and the [connect and update guide](https://fooqoo.github.io/agent-board/guide/automation/agents).

## 日本語

Agent Boardは、Claude CodeやCodexとタスク・進捗・判断を共有するローカルの作業ボードです。初回の公開版では、macOSへのHomebrewによる導入と、案内に沿ったエージェント連携の設定を提供します。

この版には2つの提供段階が混在します。ボード、タスク、判断依頼、エピック、エージェントが使うCLIは一般提供（GA）です。Docs、`connect`と`update`、タスクの受け取り、モバイルモニター、初回の案内はパブリックプレビューで、今後の版で動作が変わる可能性があります。各段階の意味と現在の制約は[機能の提供段階](https://fooqoo.github.io/agent-board/ja/guide/feature-stages)をご覧ください。GAは、不具合がないことや、今後も変更しないことを約束するものではありません。

### 変更点

- **Homebrewで導入できます。** `brew install fooqoo/tap/agboard`で、Web UIを含む署名済みのビルド済みコマンドをインストールします。Agent Boardをソースからビルドする必要はありません。
- **エージェントと連携できます。** `agboard connect`が、設定するエージェントと配置先を尋ね、Claude Code・Codex・両方のSkillとHookを導入します。書き込む前にすべての変更を表示し、変更するファイルはバックアップし、あなたが編集した内容は上書きしません。（パブリックプレビュー）
- **対象外のフォルダではHookが静かに終わります。** プロジェクトに紐付いていないフォルダでGlobal Hookが動いても、何も出力せずに正常終了し、エージェントは作業を続けられます。
- **SkillとHookを更新できます。** `agboard update`が、導入済みのSkillとHookをコマンドの版にそろえます。通常のコマンドも、導入済みのものが古いときは知らせます。（パブリックプレビュー）
- **スマートフォンから回答できます。** モバイルモニターは、ngrokとパスコードで接続します。（パブリックプレビュー）

macOS 15以降のApple SiliconまたはIntel Macが必要です。Agent Board本体はMITライセンスです。同梱する第三者のコンポーネントには、`THIRD_PARTY_NOTICES.txt`に記載したそれぞれのライセンスが適用されます。

### 不具合修正

初回の公開版のため、以前の公開版に対する修正はありません。

### 互換性に影響する変更

ありません。壊れる対象となる以前の公開版がありません。

### 必要な更新操作

新規に導入する場合、更新の操作は不要です。

```sh
brew install fooqoo/tap/agboard
cd my-project
agboard project create "My project"
agboard connect
agboard serve
```

以降の版では、`brew upgrade fooqoo/tap/agboard`でコマンドを更新します。SkillやHookが変わる版では、`agboard update`を実行し、変更されたHookをエージェントの`/hooks`で確認してください。詳しくは[インストールと起動](https://fooqoo.github.io/agent-board/ja/guide/getting-started)と[エージェントとの連携](https://fooqoo.github.io/agent-board/ja/guide/automation/agents)をご覧ください。
