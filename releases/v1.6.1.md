A release that fixes three command-line and phone board problems, and makes a missing option value an error instead of a wrong record.

## Changes

None.

## Fixes

- **`agboard epic edit --waves` accepts options after the waves.** A command such as `agboard epic edit <EPIC-ID> --waves 24 25,26 --json` failed with "waves is invalid", even for a single wave, because the option after the waves was read as another wave. Agents following the skill's examples could not set an epic's order. Options can now follow `--waves` in any order, and `--waves ""` still clears the order.
- **A forgotten value no longer records the next option as text.** In a command such as `agboard history add <id> --reason --json`, the missing reason took `--json` as its text and saved it to the task. Text options such as `--reason`, `--summary`, `--message`, and `--desc` now stop with an `invalid_argument` error when their value is missing, and nothing is recorded.
- **Archive all works on the phone after a swipe.** On the phone board, after you swiped a card in the Done lane, the Archive all button and other controls in the lane did not respond to a tap. They now respond whatever you did before.

## Breaking changes

- **Text that starts with `-` must be attached with `=`, given in a file, or read from standard input.** Text options no longer take a following word that starts with `-` as their value. `agboard history add <id> --reason "- item"` now fails, with a hint to write `--reason="- item"` instead. The same applies to a whole `TASK.md` or `EPIC.md` passed on the command line, because it starts with `---`: use `--desc="$(cat TASK.md)"`, `--desc-file TASK.md`, or `--desc-file -` with the text on standard input. Scripts and agent instructions that pass such text as a separate word need this change. The bundled skill already uses these forms.

## Required update steps

Update the command:

```sh
brew upgrade fooqoo/tap/agboard
```

Restart `agboard serve` after the upgrade. `agboard update` is not needed: this release changes no hook command, so the plugin updates itself at the first agent session after the upgrade.
