# リリースノート

Agent Boardの公開版ごとの変更点です。新しい版から順に並べています。各版のダウンロードは、[GitHub Release](https://github.com/FooQoo/agent-board/releases)にあります。

## v1.5.0

ボードがエージェントを張り付かせられるようになった版です。ボードの設定から Claude Code か Codex のセッションを起動すると、そのセッションがボードに張り付いて、依頼・回答・タスクを待ち受けます。

### 変更点

- **ボードからエージェントのセッションを起動できます。** **設定**から、プロジェクトのフォルダーでヘッドレスの Claude Code か Codex のセッションを1つ起動できます。ツールやプロジェクトを問わず、全体で1つです。セッションはボードで待ち受け、依頼・回答・タスクを受け取って処理し、また待ちます。起動の前にモデルを選びます。Claude Code は既定か `opus`・`sonnet`・`haiku`・`fable`、Codex はそのツール自身のモデル一覧から選びます。`agboard serve` の `PATH` に `claude` か `codex` があり、サインイン済みである必要があります。
- **無人で動き、承認は自動です。** ボードが起動したセッションは誰も見ておらず、あなたに確認することもありません。Claude Code は auto モード、Codex は workspace-write のサンドボックスと自動レビューで動きます。自動レビューは、あなたなら承認しない操作を通すことがあります。信頼できるプロジェクトでだけ起動し、使い終わったらボードから止めてください。起動と停止ができるのは、自分のコンピューターのボードだけで、スマホの接続からはできません。
- **自分で動き続けます。** 待機がタイムアウトしても終わらず、もう一度待ちます。セッションが自分で止まったときは、間隔を延ばしながらボードが起動し直し、何度も落ちると、もう一度起動するまで「失敗」にします。一度もボードに張り付かないセッションは入れ替えます。人への質問はボードだけで行い、回答を待つあいだも別のタスクを進めます。
- **Agent Board と一緒に起動できます。** Agent Board を起動するたびに、ボードがセッションを起動するよう設定できます。これをオフにしても、動いているセッションは止まりません。
- **張り付いているセッションが見えます。** 設定のダイアログとフッターに、セッションの状態と、ボードに張り付いているエージェントのセッション数を、ボードが起動したものと自分で起動したものに分けて表示します。自分で起動して `agboard wait --until task` で待たせているセッションも数えられ、数に上限はありません。
- **どのセッションもボードに張り付かせられます。** 新しい `wait` スキル（Claude Code では `/agent-board:wait`）で、いま話しているセッションをボードに張り付かせます。タイムアウトを指定しなければ3600秒で待ち、`idle_timeout` のたびに待ち直し、あなたが中断したときか、エラーで止まるときだけ終わります。`agboard skills resident` は、張り付いたセッションが従う手順を出力します。
- **メモだけで回答できます。** 選択肢つきの質問も、どの選択肢も合わないときは、メモだけで回答できます。**回答を送信**は、選択肢を選ぶかメモを書くと押せます。メモだけの回答は、履歴やエージェントが受け取る内容で、選択肢なしとして扱われます。
- **タスク本文のおすすめの構成。** `agboard skills task-template` のテンプレートが、「背景」「やること」「進め方」「検証結果」の見出しをすすめます（見出しはボードの言語で書きます）。すすめるだけで必須ではなく、既存のタスクもそのまま使えます。
- **エージェントが並行して worktree で進めます。** スキルは、依存関係が許すタスクは指示を待たずに着手し、Git リポジトリを変更するタスクは、それぞれ専用のブランチと worktree で進めるよう伝えます。

### 不具合修正

- ドキュメントとエディターのプレビューの図が、ページと同じフォントで描かれ、ラベルの下側が切れなくなりました。リモートアクセスのスマホで報告されていた問題です。
- ドキュメントサイトの Mermaid の図で、ラベルの下側が切れなくなりました。特にスマホや日本語で目立っていました。

### 互換性に影響する変更

ありません。

### 必要な更新操作

コマンドを更新します。

```sh
brew upgrade fooqoo/tap/agboard
```

更新後は `agboard serve` を再起動し、新しいエージェントのセッションを始めます。`agboard update` は不要です。この版はプラグインに `wait` スキルを加えただけで、hook のコマンドは変えていません。プラグインは更新後の最初のエージェントのセッションで自分で更新を始め、その次のセッションから有効になります。Codex は変わっていない hook を自分で信頼します。ボードからセッションを起動するには、`agboard serve` を動かすコンピューターに `claude` か `codex` がインストールされ、サインイン済みである必要があります。

自動更新を止めているとき、ネットワークや `git` がなくて更新できなかったとき、エージェントから更新が終わらなかったと伝えられたとき、プラグインを修復したいときは、引き続き `agboard update` が役に立ちます。

## v1.4.1

開始の承認をなくした版です。エージェントは質問への回答がそろったら、自分で AI の下書きを始め、複数のタスクを並行して進めます。また、Agent Board についてのエージェントへの指示がコマンド自身から出るようになり、プラグインの更新に手作業が要らなくなりました。

### 変更点

- **開始の承認はなくなり、エージェントが自分で下書きを始めます。** エージェントは依頼を AI の下書きにし、質問をして、回答がそろったら `agboard start <ID> --actor ai` か `agboard epic start <EPIC-ID> --actor ai` で自分で始めます。ボードに承認の依頼や承認の画面は出ません。
- **スキルが並行して進めます。** メインのエージェントが全体を取りまとめ、タスクはサブエージェントに任せます。次に動かすものは `nextTasks` で確かめます。
- **進捗表に次のタスクが並びます。** `agboard progress --json` と hook の出力に `nextTasks` が入り、おすすめの AI タスクを最大3件、`why`（理由）つきで返します。テキストの `agboard progress` では「Next tasks」に表示されます。
- **スマホの URL を渡す `remote` スキルが加わりました。** `/agent-board:remote` が、リモートアクセスのスマホ用 URL とパスコードを教えます。
- **AI に依頼がチャット形式の入力になりました。** 依頼はプレーンテキストで、下のツールバーに画像ボタンと送信ボタンが並びます。画像はサムネイルで表示されて取り除け、入力した内容がある状態で閉じるときは確認が出ます。スマホでは、シートはツールバーを見せたままキーボードの上に収まり、縮むのは入力欄だけです。iOS では、入力欄でページが拡大されなくなりました。
- **スマホの完了タブに「すべてアーカイブ」が加わりました。** カードの下にあります。
- **メッセージの帯をすっきりさせました。** ボタン名は「質問・依頼を確認」になり、帯には機能名と件数だけを出します。「受け取り待ち」の補足は帯から外しました。スマホでは、件数を押すとそのタブでメッセージ一覧が開きます。
- **スマホでメッセージ一覧のタブを横スワイプで切り替えられます。** タブが空でも、一覧のどこでスワイプしても切り替わります。
- **スマホで稼働中のアイコンが回ります。** スマホのレーンのカードでも、PC と同じように稼働中のアイコンが回転します。動きを減らす設定のときは止まったままです。
- **スマホで質問への回答が AI に依頼と同じ形になりました。** 回答はキーボードの上まで画面いっぱいに広がるシートで開き、ボタンは下部にまとまります。メッセージ一覧から開いたときは **一覧へ戻る**、カードから開いたときは **あとでやる** が並びます。質問の Markdown は表やコードブロックも含めてシートに収まり、はみ出す分はその中でスクロールします。
- **タブレットでダイアログがキーボードに隠れなくなりました。** 画面のキーボードが開くと、中央のダイアログは見えている範囲に移って縮み、ボタンに手が届きます。
- **Markdown エディターの見た目がそろいました。** すべての Markdown エディターが、AI に依頼と同じ枠と余白になります。
- **スキルの本文が `agboard` から出るようになりました。** `agboard skills` が `agent-board` スキルの指示を出力し、プラグインのスキルはそれを実行するだけです。`agboard` を更新すると、すでに開いているセッションでも、次にスキルを使うときに新しい指示になります。
- **プラグインが自分で更新されます。** エージェントのセッションが始まるとき、Agent Board のプラグインが `agboard` に同梱のものと違えば、`agboard` がバックグラウンドで入れ直し、その次のセッションから有効になります。止めたいときは `AGBOARD_NO_PLUGIN_AUTO_UPDATE=1` を設定します。
- **ドキュメントでは Agent Board を「共有ワークスペース」と呼びます。** 以前の「作業ハーネス」から変えました。

### 不具合修正

- **ボードが空のプロジェクトを表示したまま固まらなくなりました。** `agboard serve` が読み込んでいる最中にプロジェクトのファイルが削除されて書き戻されると、次に変更があるまでタスクが表示されないことがありました。読み込みのたびにファイルを読み直すようにしました。

### 互換性に影響する変更

- **`start_approval` はなくなりました。** `start_approval` という質問の種類と承認の画面はなくなりました。`start_approval` の質問をしていたエージェントやスクリプトは、計画を AI の下書きとして置き、質問をして、回答がそろったら `--actor ai` で下書きを始めるようにしてください。

### 必要な更新操作

コマンドを更新し、新しいエージェントのセッションを始めます。

```sh
brew upgrade fooqoo/tap/agboard
```

更新後は `agboard serve` を起動し直し、エージェントのセッションを新しく始めてください。`agboard update` は不要です。更新後の最初のエージェントのセッションがプラグインの更新をバックグラウンドで始め、新しいプラグインはその次のセッションから有効になります。スキルの本文は `agboard` から出るので、すでに新しいものです。Codex は、hook の定義が `agboard` に同梱のものと同じであれば、新しい hook を自分で信頼済みにします。

`agboard update` が引き続き役に立つのは、自動更新を止めているとき、ネットワークや `git` がなくて更新できなかったとき、更新が完了しなかったとエージェントに知らされたとき、プラグインを直したいときです。

## v1.4.0

質問をメッセージにまとめた版です。AI からの質問とあなたから AI への依頼が1つの帯に並び、AI が提案した計画は1枚のカードでレビューして始めます。

### 変更点

- **ボードにメッセージが並びます。** レーンの上の**メッセージ**の帯に、**AI の質問**（質問と、承認を待つ計画）と**あなたの依頼**（受け取り待ち）の件数が出ます。**一覧を開く**から、質問に答える、計画をレビューする、依頼を取り下げる、ができます。スマホでは一覧が下からのシートで開きます。
- **AI に依頼できます。** ヘッダーと、スマホの帯にある **AI に依頼** から、タスクと同じリッチエディターで書いた依頼を、貼り付けや添付の画像と一緒にエージェントへ送れます。依頼はタスクにもエピックにも紐づかず、エージェントが受け取るまで**受け取り待ち**と表示されます。自分でタスクを追加するときは、隣のメニューの**タスクを手動で追加**を使います。
- **計画は人が始めます。** エージェントが作ったタスクとエピックは AI の下書きになり、レーンにカードとしては並びません。Todo の先頭にある破線の**提案中の計画**カードか、一覧のその行から、ゴール・始まるタスク・未回答の質問を並べたレビューが開きます。**この計画で始める**で始まり、**あとでやる**ではそのままです。計画に関わる質問に返事がない間は始められません。計画を始められるのは人だけで、コマンドでは `agboard epic start <EPIC-ID>` か `agboard start <id>` を使います。
- **質問と依頼は1件1ファイルです。** 質問と依頼はそれぞれ1つの Markdown ファイルで、回答や受理も同じファイルに書かれます。質問には選択肢があるかないかだけで、選択肢がなければ文章で答えます。コマンドは `agboard message ask`、`answer`、`send`、`accept`、`ls`、`show`、`withdraw`、`wait`、`link`、`unlink` です。
- **エージェントが依頼を受け取ります。** 受け取り待ちの依頼は進捗表と hook の出力に出て、`agboard wait --until task` はタスクより先に依頼を返します。エージェントは `agboard message accept` で依頼を受け取るので、2つのエージェントが同じ依頼を拾うことはありません。
- **エージェントが回答を受け取ります。** まだエージェントが受け取っていない回答は進捗表と hook の出力に出て、`agboard wait --until task` は最初にそれを返します。エージェントは `agboard message accept` で回答を受け取ったことを記録します。`agboard message ask` と `agboard message wait` は、返した回答をその場で受け取ります。受け取られるまで、質問は **AI の質問** に **回答済み・AI の受け取り待ち** として残り、あなたの回答を読めます。あなたを待っているものとしては数えません。
- **待ちの条件が簡単になりました。** タスクが待ち（Pending）になるのは、参照している質問に返事がないときと、参照しているファイルが読めないときだけです。
- **日本語では「完了条件」と呼びます。** 日本語の画面とドキュメントで、受け入れ条件を完了条件と呼ぶようにしました。
- **ガイドを新しい仕事の進め方に合わせました。** ユーザーガイドで、メッセージの帯、AI に依頼、計画のレビューを説明し、エージェントに仕事を任せる流れに沿ってページを並べ直しました。

### 不具合修正

- `agboard edit --desc-file` でタスクの本文を置き換えても、タスクから質問への参照が消えなくなりました。
- iOS Safari で、幅の広い表の列の文字が拡大されなくなりました。
- スマホやタブレットで、リッチエディター（AI に依頼、タスクの追加・編集）に入力しても、iOS で画面が拡大されなくなりました。
- メッセージの帯がレーンの上に余白を保ち、タッチ画面の混み合ったヘッダーでもプロジェクトの切り替えが指で押せる大きさを保つようになりました。
- 初回ガイドを開いたあとにボードが表示されても、ガイドの強調表示が外れなくなりました。

### 互換性に影響する変更

- **`agboard qa` は `agboard message` に置き換わりました。** API も `/api/projects/{id}/qa…` から `/api/projects/{id}/messages…` に変わり、ボードの Summary は `messages` を返します。
- **開始の承認はなくなりました。** エージェントは「この計画で始めますか」という質問をしなくなりました。計画を AI の下書きとして置き、人がボードかコマンドから始めます。質問の `kind` もなくなりました。
- **`isDraft` は `draft` に置き換わりました。** タスクとエピックのファイルと API では、`draft` に `null`、`human`（人の書きかけ）、`ai`（エージェントの提案）のいずれかが入ります。
- **これまでの質問は一度だけ変換されます。** 最初に読んだときに、未回答の質問は新しいファイルへ移り、回答済みの質問は捨てられます。未回答の開始の承認は、対象のタスクが AI の下書きになり、ボードから始められます。

### 必要な更新操作

コマンドを更新し、プラグインを同じバージョンにそろえます。

```sh
brew upgrade fooqoo/tap/agboard
agboard update
```

`agboard update` が必要です。スキルが、エージェントに `agboard message` で依頼と回答を受け取り、計画を AI の下書きとして置くよう伝えるようになりました。プラグインのバージョンはコマンドとそろっている必要があり、そろっていないと新しいエージェントのセッションで実行を求められます。更新後は `agboard serve` を起動し直し、新しいスキルを読み込むため、エージェントのセッションも新しく始めてください。

## v1.3.0

スマホからボード全体を使えるようにした版です。幅768px未満ではボードを1レーンずつ表示し、ngrokのアドレスからはパスコードの先で同じボードが開きます。

### 変更点

- **どの画面でも同じボードです。** 幅768px未満ではボードがスマホ用の画面になり、768px以上ではレーンを並べて表示します。モバイルモニターは別のページではなくなりました。ngrokのアドレスからもこのボードが開き、ヘッダーのプロジェクト切り替えにはPCと同じくすべてのプロジェクトが並びます。
- **スマホでは1レーンずつ表示します。** 上部のタブに、各レーンの名前とカードの件数が出ます。タブを押すか横にスワイプすると、レーンが切り替わります。
- **スマホでカードを移動・アーカイブできます。** カードを長押しして選び、スワイプするとボタンが出ます。隣のレーンへの移動と、確認を経てのアーカイブができます。完了レーンには**まとめてアーカイブ**があり、レーンが空のときは押せません。完全な削除は、これまでどおりアーカイブ画面から行います。
- **「未回答の質問」の帯は畳んだ状態で始まります。** 見出しに未回答の質問の数が出ます。開くと一覧が出て、1つだけ選んで答えることも、**まとめて答える**で順に答えることもできます。PCでもスマホでも同じです。
- **`agboard remote`でスマホ用のリンクを受け取れます。** ngrokの接続中に`agboard --project "<名前>" remote`を実行すると、接続の状態、そのプロジェクトのアドレス、パスコードが表示されます。`--json`を付けるとJSONで出力します。PCでだけ動き、何も起動しません。接続の画面を開かなくても、エージェントからリンクを受け取れます。
- **初回ガイドがスマホでもngrok経由でも動きます。** ガイドはブラウザの中だけで進むようになりました。サンプルカードとエージェント役の動きは画面にだけ描かれ、ボードには「一度見たかどうか」だけが残ります。設定の**チュートリアル**にある**試してみる**で、PCでもスマホでも再表示できます。
- **指で操作しやすくなりました。** タッチ画面ではボタンを大きくし、カードはつまみ部分からすぐドラッグできます。タブレットやスマホでキーボードが開いている間も、ボードとダイアログの大きさは変わらず、入力中の欄はキーボードの上に表示されます。

### 不具合修正

- タッチ画面でダイアログや回答シートを開いたとき、欄を選ぶ前にキーボードが出なくなりました。
- タブレットでキーボードを開いても、ボードと開いているダイアログがキーボードの上の狭い範囲に押し縮められなくなりました。
- タブレットを横向きにしても、**ドキュメント**の文字が表示されたままになりました。

### 互換性に影響する変更

- **ngrokのアドレスからボード全体を使えます。** 4桁のパスコードを入力した人は、最長12時間、PCと同じようにボードを使えます。すべてのプロジェクトを読み、タスクとエピックの追加・編集・移動・アーカイブ・削除ができます。以前の版では、スマホからできるのは質問への回答と条件のチェックだけでした。接続の設定だけはPCに残ります。パスコードは、ボードを使わせてよい人にだけ伝えてください。
- **末尾が`/monitor/`のアドレスは使えなくなりました。** 別ページだったモニターとそのAPIを廃止したため、古いリンクは「見つかりません」になります。新しいアドレスへの転送はありません。PCでモバイル接続の設定を開いて今のQRコードを読み取り直し、保存したブックマークも新しいアドレスに置き換えてください。

### 必要な更新操作

コマンドを更新してから、プラグインを同じ版にそろえます。

```sh
brew upgrade fooqoo/tap/agboard
agboard update
```

`agboard update`が必要です。Skillに、`agboard remote`でボードをスマホで開く手順が加わりました。また、プラグインの版をコマンドとそろえないと、新しいエージェントのセッションで実行を求められます。更新後は`agboard serve`を再起動して、スマホに新しいボードを読み込ませてください。

## v1.2.1

タスクの質問にカードから答えてすぐ送れるようにし、ボタンを続けて押しても問題が起きないようにした版です。

## v1.2.0

エージェントに要望を任せ、質問に1か所でまとめて答えられるようにした版です。エージェントの準備も、プラグインを1回入れるだけで済むようになりました。

### 変更点

- **1つのコマンドでエージェントを準備できます。** `agboard setup` が、SkillとHookをまとめたAgent Boardのプラグインを、Claude Code、Codex、またはその両方に入れます。どのフォルダーでも動き、プロジェクトは要りません。`--agent`と`--yes`を付ければ、何も聞かずに進みます。Codexでは、同意を得たうえでプラグインのHookを信頼済みにします。
- **プラグインを最新に保てます。** `agboard update` が、プラグインをコマンドと同じ版に上げ、Codexの新しいHookを信頼し直します。プラグインとコマンドの版が違うと、新しいエージェントのセッションが実行を促します。
- **要望を任せ、計画を1回承認するだけで進みます。** いくつものタスクにわたる作業を頼むと、エージェントはまず仮の計画をボードに載せ、自分では決められないことを質問し、開始の承認を1回だけ求めます。承認するまで、その計画のタスクは待ちます。
- **質問に1か所で答えられます。** 質問はプロジェクトに属し、タスクは自分が待っている質問を参照します。レーンの上の**未回答の質問**の帯に、開いている質問がすべて並びます。質問に順に答え、最後に**まとめて送る**で一度に送ります。ボードでもスマートフォンでも同じです。会話中のエージェントはチャットでも同じ質問をし、ボードとチャットのうち先に届いた答えが有効になります。
- **タスクを動かしても質問は取り下げられません。** 質問は、答えるかエージェントが取り下げるまで開いたままです。
- **ボードが自動で起動します。** 待っている質問、`wait`、Hookなど、サーバーが要るコマンドは、サーバーを裏で起動し、プロジェクトのボードをブラウザーで1回開きます。使われないまま30分たつと止まります。`agboard open` で、今のプロジェクトのボードを開けます。

### 不具合修正

- このPCに保存したngrokのトークンを使ってよいかをOSが確認している間（更新した後など）も、ボードが応答し続けるようになりました。確認の答えを待つのは、保存したトークンでの接続と、トークンの削除だけです。
- エージェントが画像を読んだり、出力の長いコマンドを実行したりしたあとも、Hookがボードの進行表を渡すようになりました。これまでは`hook_input_too_large`を返し、エージェントがボードを読み直す必要がありました。

### 互換性に影響する変更

- `agboard connect` はなくなりました。SkillとHookは、`agboard setup` がプラグインとして入れます。
- `agboard update` はプラグインを更新するコマンドになりました。プラグインが入っていないエージェントは飛ばし、`agboard setup` の実行を案内します。
- `agboard state <id> pending` はなくなりました。エージェントは `agboard qa ask` で質問し、`agboard qa wait` で答えを待ちます。
- 以前の版で開いたままの質問は引き継がれません。更新すると、その質問はタスクから消えます。

### 必要な更新操作

更新する前に、ボードの開いている質問に答えておいてください。

そのあと、コマンドを更新してプラグインを入れます。

```sh
brew upgrade fooqoo/tap/agboard
agboard setup
```

今回はまだプラグインが入っていないので、`agboard update` では足りません。一度 `agboard setup` を実行してください。次の版からは `agboard update` だけで済みます。

`agboard connect` で入れたSkillとHookは、自動では消えません。Hookが二重に動かないよう、`agent-board` のSkillフォルダーと、エージェントの設定にある `agboard hook` を実行するHookの項目を消してください。

## v1.0.0

Agent Boardは、Claude CodeやCodexとタスク・進捗・判断を共有するローカルの作業ボードです。初回の公開版では、macOSへのHomebrewによる導入と、案内に沿ったエージェント連携の設定を提供します。

この版には2つの提供段階が混在します。ボード、タスク、判断依頼、エピック、エージェントが使うCLI、`connect`と`update`、初回の案内は一般提供（GA）です。ドキュメント、タスクの受け取り、モバイルモニターはパブリックプレビューで、今後の版で動作が変わる可能性があります。各段階の意味と現在の制約は[機能の提供段階](./guide/feature-stages.md)をご覧ください。GAは、不具合がないことや、今後も変更しないことを約束するものではありません。

### 変更点

- **Homebrewで導入できます。** `brew install fooqoo/tap/agboard`で、Web UIを含む署名済みのビルド済みコマンドをインストールします。Agent Boardをソースからビルドする必要はありません。
- **エージェントと連携できます。** `agboard connect`が、設定するエージェントと配置先を尋ね、Claude Code・Codex・両方のSkillとHookを導入します。書き込む前にすべての変更を表示し、変更するファイルはバックアップし、あなたが編集した内容は上書きしません。
- **対象外のフォルダではHookが静かに終わります。** プロジェクトに紐付いていないフォルダでGlobal Hookが動いても、何も出力せずに正常終了し、エージェントは作業を続けられます。
- **SkillとHookを更新できます。** `agboard update`が、導入済みのSkillとHookをコマンドの版にそろえます。通常のコマンドも、導入済みのものが古いときは知らせます。
- **スマートフォンから回答できます。** モバイルモニターは、ngrokとパスコードで接続します。（パブリックプレビュー）

macOS 15以降のApple SiliconまたはIntel Macが必要です。Agent Board本体はMITライセンスです。同梱する第三者のコンポーネントには、`THIRD_PARTY_NOTICES.txt`に記載したそれぞれのライセンスが適用されます。

### 不具合修正

初回の公開版のため、以前の公開版に対する修正はありません。

### 互換性に影響する変更

ありません。壊れる対象となる以前の公開版がありません。

### 必要な更新操作

新規に導入する場合、更新の操作は不要です。

```sh
brew install fooqoo/tap/agboard
cd my-project
agboard project create "My project"
agboard connect
agboard serve
```

以降の版では、`brew upgrade fooqoo/tap/agboard`でコマンドを更新します。SkillやHookが変わる版では、`agboard update`を実行し、変更されたHookをエージェントの`/hooks`で確認してください。詳しくは[インストールと起動](./guide/getting-started.md)と[エージェントとの連携](./guide/delegate/agents.md)をご覧ください。
