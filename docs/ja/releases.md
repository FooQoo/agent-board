# リリースノート

Agent Boardの公開版ごとの変更点です。新しい版から順に並べています。各版のダウンロードは、[GitHub Release](https://github.com/FooQoo/agent-board/releases)にあります。

## v1.6.1

エピックのウェーブをコマンドラインから設定できない不具合を直した版です。

### 変更点

ありません。

### 不具合修正

- **`agboard epic edit --waves` のあとにほかのオプションを続けられるようになりました。** `agboard epic edit <EPIC-ID> --waves 24 25,26 --json` のように打つと、ウェーブが 1 つだけでも「waves is invalid」で失敗していました。ウェーブのあとのオプションまでウェーブの値として読んでいたためで、スキルの例どおりに打つエージェントがエピックの順序を設定できませんでした。いまはオプションをどの順番で並べても動き、`--waves ""` で順序を消すこともこれまでどおりできます。

### 互換性に影響する変更

ありません。

### 必要な更新操作

コマンドを更新します。

```sh
brew upgrade fooqoo/tap/agboard
```

更新したら `agboard serve` を再起動してください。`agboard update` は不要です。この版はフックのコマンドを変えていないので、プラグインは更新後の最初のエージェントのセッションで自動的に更新されます。

## v1.6.0

作業の成果をスマホに届ける版です。エージェントが作業を続けながら見てもらえる成果を届け、ボードが iPhone に通知します。スマホのボードには、下部バー、アーカイブ一覧、新しいレイアウトが加わりました。

### 変更点

- **エージェントが成果を届けます。** エージェントは、見てもらえる最初のもの(動画の下書きや画面のキャプチャなど)を `agboard result add` で記録し、返事を待たずに作業を続けます。成果には、タイトル、短い要約、最大 20 枚の画像、主な成果物へのリンクや保存場所があり、途中経過か最終かが示されます。成果は返事の要らない通知です。あなたの選択が必要なことは、これまでどおり質問として尋ねます。`agboard result ls` でタスクの成果を一覧できます。最終の成果がないままタスクを終えようとしたエージェントには、記録するよう促します。
- **成果をボードで読めます。** タスクの詳細に新しく**成果**タブが加わりました。PC でもスマホでも使えます。成果を新しい順に並べ、バッジ、バージョン、時刻、タイトル、要約、拡大してスワイプで見比べられる画像を表示します。Web のリンクは新しいタブで開き、それ以外の値はテキストで表示します。プロジェクト、タスク、バージョンを指すアドレスからも成果を開けます。
- **iPhone で通知を受け取れます。** ボードをホーム画面に追加し、そのアイコンから開いて**通知を有効にする**を選びます。ほかのアプリやアカウントは要りません。通知は PC からスマホまで暗号化されます。**設定**の**通知設定**で、成果、判断が必要な質問、履歴の追加を個別に切り替えられます。通知にはカードのタイトルと短い 1 行が表示され、タップすると成果、質問、カードが開きます。
- **成果の要約が届きます。** ボードは一定の間隔(30 分、1 時間、2 時間、4 時間、またはオフ。最初は 1 時間)ごとに、その間の成果の要約を記録します。**質問と依頼**に加わった**要約**タブで一覧でき、ごみ箱ボタンまたはスワイプで削除できます。要約の通知をタップすると、このタブが開きます。
- **スマホを覚えます。** 合言葉を入力すると、そのスマホが登録されます。12 時間のセッションが切れたあとも、接続を一時停止して再開したあとも、PC を再起動したあとも、合言葉なしでボードが開き直ります。接続のダイアログに**登録済みのスマホ**が表示され、**登録を解除**を選ぶとそのスマホはすぐにサインアウトされます。**接続を停止**は**接続を一時停止**になり、トークンと登録済みのスマホは残ります。
- **同じアドレスを使い続けられます。** ngrok のアカウントが所有するドメインを入力する(**ngrokのドメイン**欄、または環境変数 `AGBOARD_NGROK_DOMAIN`)と、起動のたびにアドレスが同じになり、ブックマークやホーム画面のアイコンが使い続けられます。
- **リモートアクセスをコマンドラインで設定できます。** `agboard setup remote` でドメイン、トークン、接続のオン・オフを保存できます。ターミナルでの `agboard setup` でも、設定するか尋ねます。`agboard show remote` は保存された設定と接続の状態を表示し、`--project` を付けるとスマホのアドレスと合言葉を表示します。
- **スマホのレイアウトを一新しました。** 「**ボード**」「**メッセージ**」「**依頼**」「**アーカイブ**」「**設定**」の下部バーが、メッセージの帯に代わりました。メッセージのアイコンには、未回答の質問の数が表示されます。ドロワーはボードの上にせり上がり、下部バーはその手前に残ります。レーンを引き下げると更新できます。ホーム画面のアプリでは、ヘッダーなどがステータスバー、ダイナミックアイランド、ホームインジケーターに重ならず、タブレットのキーボードが入力欄を隠すこともなくなりました。
- **スマホでアーカイブしたタスクを見直し、戻せます。** 下部バーの**アーカイブ**で、アーカイブ済みのタスクをレーンと同じカードで新しい順に表示します。カードには戻り先のレーンとアーカイブした日が付きます。カードを左にスワイプすると元のレーンに戻り、一覧からすぐに消えます。件数が多くても滑らかにスクロールできます。完了のカードをまとめてアーカイブするには、完了レーンからさらに左へスワイプするか（スワイプ中にまとめてアーカイブのアイコンが現れます）、カードの下の**まとめてアーカイブ**を使います。
- **カードの移動が速くなりました。** カードを別のレーンにドラッグしたとき、またはスマホでレーンのボタンを押したときは、確認なしですぐに移動します。そのあいだにカードが別の場所へ動いていたときは、何も変わらず、いまのレーンが通知されます。
- **回答に画像を付けられます。** 回答には画像を付けられ(選択または貼り付け、最大 20 枚・合計 50 MiB)、回答と一緒にエージェントへ渡ります。エージェントも `message ask` で質問に画像を付けられます。スマホでは、選んだ画像がタップしやすい大きさで並び、タップすると拡大します。拡大した画像はスワイプで切り替えられ、キーボードが開いているときも、**依頼を送信**や**回答を送信**を 1 回タップするだけで送れます。
- **エピックをウェーブで並べられます。** エピックのタスクは、ウェーブの順に進みます。同じウェーブのタスクは並行して進められ、前のウェーブのタスクがすべて完了すると次のウェーブが始まります。ウェーブは、エピックの進捗パネルでドラッグするか、`agboard epic edit --waves` で編集します。次のタスクの一覧、`agboard wait`、常駐エージェントは、後ろのウェーブのタスクを渡しません。
- **エージェントにターン終了時のチェックリストを返します。** Claude Code や Codex のエージェントがターンを終えるとき、フックが、チャットだけで尋ねた質問や、記録していない成果を 1 回だけ知らせます。エージェント向けの指示は短い話題ごとに分かれ、エージェントは設定で選んだ言語で返信し続けます。
- **常駐エージェントが分かりやすくなりました。** **常駐セッション**は**常駐エージェント**になり、ダイアログにログの欄が加わり、直近 5 回の起動のログが残ります。作業中のエージェントを止めるときは、確認が入ります。サブエージェントの終了待ちや、自分で起動したセッションの利用中の状態も表示され、人の確認を待つ作業は、エラーではなく**保留中**と表示されます。エージェントがエラーで止まったときは、作業中だったタスクに履歴が残り、待機中に戻るので、別のエージェントが引き継げます。
- **ほかの改善があります。** 読み込み中と更新中は、文字の代わりに作業中のタスクと同じ回転するマークで示します。設定のボタンが中央に揃い、ドキュメントに AI-DLC、仕様駆動開発との比較が加わり、ホーム画面のアイコンは白くなりました。

### 不具合修正

- **何も変えない保存で待機が起きなくなりました。** `agboard wait` で待っているエージェントが、別のツールがタスクのファイルを内容を変えずに保存しただけで起こされることがありました。変更を確かめてから起こすようにしたため、実際の変更は約 0.25 秒遅れて通知されます。
- **ngrok を再起動しても止まらなくなりました。** 停止したあとにリモート接続を再び始めるとき、待ち続けることがなくなりました。
- **スマホの表示の乱れが減りました。** スクロールバーがカードに重ならなくなり、ヘッダー、下部バー、ドロワーが画面の端に重ならなくなりました。

### 互換性に影響する変更

- この版が保存する次の 2 つのファイルは、古い版の `agboard` では読めません。成果があるタスクは `task.json` に成果を記録し、保存した ngrok のドメインは `monitor-connection.json` に書かれます。v1.6.0 でデータを使ったあとは、同じデータで古い版の `agboard` に戻さないでください。
- エピックのタスクの順序は `waves` になりました。`agboard epic edit --priority` と `EPIC.md` の `priority` は `--waves` と `waves` に置き換わりました。既存の `priority` は適用されなくなるため、ウェーブを設定し直してください。
- `agboard remote` は `agboard show remote` になりました(アドレスと合言葉の表示には `--project` を付けます)。

### 必要な更新操作

コマンドを更新します。

```sh
brew upgrade fooqoo/tap/agboard
```

アップグレード後に `agboard serve` を再起動し、`agboard update` を 1 回実行してください。この版では `agboard update` が必要です。Claude Code と Codex の Agent Board フックが、エージェントのターン終了時(`Stop`)にも動くようになり、Codex はフックの定義が変わるとあらためて信頼するまでプラグインのフックを実行しないためです。iPhone で通知を受け取るには、ボードをホーム画面に追加し、設定で有効にします。

## v1.5.2

最初の一歩を「AI に依頼」から説明し直した版です。依頼を送ると、エージェントがタスクに分けて計画し、あなたが質問に答えると、タスクが自動で完了まで進みます。

### 変更点

- **初回ガイドを作り直しました。** Agent Board での仕事の進め方どおりにたどります。**AI に依頼**でサンプルの依頼を送ると、エージェントがエピックと、完了条件の付いた下書きのタスクに分けます。エージェントの質問に答えると、計画が始まり、カードが完了まで進みます。これまでどおりブラウザの中で再現するだけで、ボードには何も変更を加えません。**設定**の**チュートリアル**にある**試してみる**から、いつでも開き直せます。
- **デモ動画とガイドを新しくしました。** ドキュメントサイトの動画と「はじめに」は、**AI に依頼**での依頼から自動での完了までの、同じ流れで紹介します。クイックスタートは**AI に依頼**から始まり、手で試す手順では、依頼を送り、それを受け取るエージェントの役を演じます。ガイドのスクリーンショットは、いまのボードで撮り直しました。

### 不具合修正

## v1.5.1

PC のボードをタブレットで使いやすくし、止めたサーバーが残り続ける問題を直し、タスクの追加をエージェントと CLI に任せる版です。

### 変更点

- **タブレットでタブをスワイプで切り替えられます。** タッチ操作の画面の PC のボードで、タスクの詳細パネルを左右にスワイプすると隣のタブへ移ります。スマートフォンでタスクのタブを切り替えるときと同じく、隣のタブが指に合わせて動きます。**メッセージ**のモーダルも、本文のどこをスワイプしてもタブが切り替わります。マウスではパネルは動かないので、文字を選択できます。ボタン、リンク、コード、画像、横にスクロールする表の上から始めたスワイプは、その要素の操作になります。
- **タブレットのキーボードの上で入力できます。** **AI に依頼**、回答、タスクのエディターなどのダイアログでソフトウェアキーボードが開くと、ダイアログはヘッダーとフッターを詰め、入力していない欄を隠します。入力中の欄がキーボードの上に見えたままになります。
- **リモート接続の設定はコンピューターだけで扱います。** リモートアクセスで開いたページでは、PC の表示になる幅のタブレットでも、**設定**に**リモート接続**の行が出なくなりました。接続の開始と停止は、`agboard serve` を動かしているコンピューターで行ってください。

### 不具合修正

- `agboard stop` やボードからの停止で、キーチェーンへの問い合わせが応答を待っているとき（誰も答えていない macOS の許可ダイアログなど）でも、サーバーが終了するようになりました。これまでは、止まったと表示したあともサーバーが動き続けることがありました。
- iPad で、テキスト欄にフォーカスがないとき（ピンチで拡大したあとなど）に、中央に出るダイアログが画面の上端へ飛ばなくなりました。
- ヘッダーの**ドキュメント**、**エピック**、**アーカイブ**のボタンの幅をそろえました。幅の狭いウィンドウでは、アイコンだけを表示します。

### 互換性に影響する変更

ボードから手でタスクを追加するフォームはなくなりました。**AI に依頼**の横のメニューと、その**タスクを手動で追加**は削除されています。エージェントには**AI に依頼**で依頼するか、`agboard add` でタスクを追加してください（[CLI](https://fooqoo.github.io/agent-board/ja/guide/reference/cli)を参照）。エージェントと CLI によるタスクの作成はこれまでどおりで、既存のタスクを全画面のエディターで編集する操作も変わりません。

### 必要な更新操作

コマンドを更新します。

```sh
brew upgrade fooqoo/tap/agboard
```

更新したら `agboard serve` を再起動してください。`agboard update` は不要です。この版はフックのコマンドを変えていないので、プラグインは更新後の最初のエージェントのセッションで自動的に更新されます。

## v1.5.0

ボードがエージェントを張り付かせられるようになった版です。ボードの設定から Claude Code か Codex のセッションを起動すると、そのセッションがボードに張り付き、依頼・回答・タスクを、セッションが待機中のときにボードが届けます。

### 変更点

- **ボードからエージェントのセッションを起動できます。** **設定**の**常駐セッション**の行で**常駐セッションの設定**を選ぶと開くダイアログから、プロジェクトのフォルダーでヘッドレスの Claude Code か Codex のセッションを1つ起動できます。ツールやプロジェクトを問わず、全体で1つです。ボードは、セッションが待機中のときだけ、あなたの依頼、セッション自身の質問への回答、着手できるタスクを送ります。未対応の依頼はまとめて1通、回答もまとめて1通、タスクは1つずつです。セッション自身が `agboard wait` を動かすことはありません。起動の前にモデルを選びます。Claude Code は既定か `opus`・`sonnet`・`haiku`・`fable`、Codex はそのツール自身のモデル一覧から選びます。`agboard serve` の `PATH` に `claude` か `codex` があり、サインイン済みである必要があります。
- **無人で動き、承認は自動です。** ボードが起動したセッションは誰も見ておらず、あなたに確認することもありません。Claude Code は auto モード、Codex は workspace-write のサンドボックスと自動レビューで動きます。自動レビューは、あなたなら承認しない操作を通すことがあります。信頼できるプロジェクトでだけ起動し、使い終わったらボードから止めてください。ダイアログにも毎回この注意が出ます。起動と停止ができるのは、自分のコンピューターのボードだけで、スマホの接続からはできません。リモートアクセスで開いたページでは、**設定**に**常駐セッション**の行は出ません。
- **ボードが順に仕事を送ります。** セッションが待機中になると、ボードは、そのセッションが出した質問への回答、開いている依頼、着手できる最初のタスクの順に送ります。すでに承認した依頼や、実行中のタスクは送り直しません。Claude Code は双方向の stream-json、Codex は `codex app-server` で動かすので、wait のコマンドがなくても、張り付いているか・作業中か・待機中かをボードが把握できます。権限の扱いはこれまでどおりです。
- **自分で動き続けます。** セッションが自分で止まったときは、間隔を延ばしながらボードが起動し直し、何度も落ちると、もう一度起動するまで「失敗」にします。一度もボードに張り付かないセッションは入れ替えます。人への質問はボードだけで行い、回答を待つあいだも別のタスクを進めます。
- **処理できない項目は、繰り返さずに表示します。** 項目が処理されないと、ボードは30秒後、次に5分後に送り直し、3回失敗したらその項目を送るのをやめます。ダイアログと PC のフッターに**処理できない項目があります**と、各項目の名前と理由が出ます。ボードで自分で処理するか、セッションを再起動してください。
- **Agent Board と一緒に起動できます。** ダイアログで**Agent Board の起動時に自動で起動する**をオンにすると、Agent Board を起動するたびに、開いていたツール・モデル・プロジェクトでボードがセッションを起動します。これをオフにしても、動いているセッションは止まりません。
- **張り付いているセッションが見えます。** ダイアログに、セッションの状態（作業中は**タスク作業中**のままです）と、ボードに張り付いているエージェントのセッション数を、ボードが起動したものと自分で起動したものに分けて表示します。PC ではフッターに、セッションの起動中か自動起動がオンのあいだ、ツール名と点が出て、押すとダイアログが開きます。スマホのボードでは、下の状態表示に接続状態に続けて同じ表示が出ますが、見るだけです。自分で起動して `agboard wait --until task` で待たせているセッションには影響がありません。これまでどおりボードを待ち、ボードのセッションと並べて外部セッションとして数えられ、数に上限はありません。
- **どのセッションもボードに張り付かせられます。** 新しい `wait` スキル（Claude Code では `/agent-board:wait`）で、いま話しているセッションをボードに張り付かせます。タイムアウトを指定しなければ3600秒で待ち、`idle_timeout` のたびに待ち直し、あなたが中断したときか、エラーで止まるときだけ終わります。`agboard skills resident` は、張り付いたセッションが従う手順を出力します。
- **メモだけで回答できます。** 選択肢つきの質問も、どの選択肢も合わないときは、メモだけで回答できます。**回答を送信**は、選択肢を選ぶかメモを書くと押せます。メモだけの回答は、履歴やエージェントが受け取る内容で、選択肢なしとして扱われます。
- **タスク本文のおすすめの構成。** `agboard skills task-template` のテンプレートが、「背景」「やること」「進め方」「検証結果」の見出しをすすめます（見出しはボードの言語で書きます）。すすめるだけで必須ではなく、既存のタスクもそのまま使えます。
- **エージェントが並行して worktree で進めます。** スキルは、依存関係が許すタスクは指示を待たずに着手し、Git リポジトリを変更するタスクは、それぞれ専用のブランチと worktree で進めるよう伝えます。

## v1.4.0

質問をメッセージにまとめた版です。AI からの質問とあなたから AI への依頼が1つの帯に並び、AI が提案した計画は1枚のカードでレビューして始めます。

### 変更点

- **ボードにメッセージが並びます。** レーンの上の**メッセージ**の帯に、**AI の質問**（質問と、承認を待つ計画）と**あなたの依頼**（受け取り待ち）の件数が出ます。**一覧を開く**から、質問に答える、計画をレビューする、依頼を取り下げる、ができます。スマホでは一覧が下からのシートで開きます。
- **AI に依頼できます。** ヘッダーと、スマホの帯にある **AI に依頼** から、タスクと同じリッチエディターで書いた依頼を、貼り付けや添付の画像と一緒にエージェントへ送れます。依頼はタスクにもエピックにも紐づかず、エージェントが受け取るまで**受け取り待ち**と表示されます。自分でタスクを追加するときは、隣のメニューの**タスクを手動で追加**を使います。
- **計画は人が始めます。** エージェントが作ったタスクとエピックは AI の下書きになり、レーンにカードとしては並びません。Todo の先頭にある破線の**提案中の計画**カードか、一覧のその行から、ゴール・始まるタスク・未回答の質問を並べたレビューが開きます。**この計画で始める**で始まり、**あとでやる**ではそのままです。計画に関わる質問に返事がない間は始められません。計画を始められるのは人だけで、コマンドでは `agboard epic start <EPIC-ID>` か `agboard start <id>` を使います。
- **質問と依頼は1件1ファイルです。** 質問と依頼はそれぞれ1つの Markdown ファイルで、回答や受理も同じファイルに書かれます。質問には選択肢があるかないかだけで、選択肢がなければ文章で答えます。コマンドは `agboard message ask`、`answer`、`send`、`accept`、`ls`、`show`、`withdraw`、`wait`、`link`、`unlink` です。
- **エージェントが依頼を受け取ります。** 受け取り待ちの依頼は進捗表と hook の出力に出て、`agboard wait --until task` はタスクより先に依頼を返します。エージェントは `agboard message accept` で依頼を受け取るので、2つのエージェントが同じ依頼を拾うことはありません。
- **エージェントが回答を受け取ります。** まだエージェントが受け取っていない回答は進捗表と hook の出力に出て、`agboard wait --until task` は最初にそれを返します。エージェントは `agboard message accept` で回答を受け取ったことを記録します。`agboard message ask` と `agboard message wait` は、返した回答をその場で受け取ります。受け取られるまで、質問は **AI の質問** に **回答済み・AI の受け取り待ち** として残り、あなたの回答を読めます。あなたを待っているものとしては数えません。
- **待ちの条件が簡単になりました。** タスクが待ち（Pending）になるのは、参照している質問に返事がないときと、参照しているファイルが読めないときだけです。
- **日本語では「完了条件」と呼びます。** 日本語の画面とドキュメントで、受け入れ条件を完了条件と呼ぶようにしました。
- **ガイドを新しい仕事の進め方に合わせました。** ユーザーガイドで、メッセージの帯、AI に依頼、計画のレビューを説明し、エージェントに仕事を任せる流れに沿ってページを並べ直しました。

### 不具合修正

- `agboard edit --desc-file` でタスクの本文を置き換えても、タスクから質問への参照が消えなくなりました。
- iOS Safari で、幅の広い表の列の文字が拡大されなくなりました。
- スマホやタブレットで、リッチエディター（AI に依頼、タスクの追加・編集）に入力しても、iOS で画面が拡大されなくなりました。

### 互換性に影響する変更

- **開始の承認はなくなりました。** エージェントは「この計画で始めますか」という質問をしなくなりました。計画を AI の下書きとして置き、人がボードかコマンドから始めます。質問の `kind` もなくなりました。

```sh

```

`agboard update` が必要です。スキルが、エージェントに `agboard message` で依頼と回答を受け取り、計画を AI の下書きとして置くよう伝えるようになりました。プラグインのバージョンはコマンドとそろっている必要があり、そろっていないと新しいエージェントのセッションで実行を求められます。更新後は `agboard serve` を起動し直し、新しいスキルを読み込むため、エージェントのセッションも新しく始めてください。

エージェントに要望を任せ、質問に1か所でまとめて答えられるようにした版です。エージェントの準備も、プラグインを1回入れるだけで済むようになりました。

### 変更点

- **1つのコマンドでエージェントを準備できます。** `agboard setup` が、SkillとHookをまとめたAgent Boardのプラグインを、Claude Code、Codex、またはその両方に入れます。どのフォルダーでも動き、プロジェクトは要りません。`--agent`と`--yes`を付ければ、何も聞かずに進みます。Codexでは、同意を得たうえでプラグインのHookを信頼済みにします。
- **プラグインを最新に保てます。** `agboard update` が、プラグインをコマンドと同じ版に上げ、Codexの新しいHookを信頼し直します。プラグインとコマンドの版が違うと、新しいエージェントのセッションが実行を促します。
- **要望を任せ、計画を1回承認するだけで進みます。** いくつものタスクにわたる作業を頼むと、エージェントはまず仮の計画をボードに載せ、自分では決められないことを質問し、開始の承認を1回だけ求めます。承認するまで、その計画のタスクは待ちます。
- **質問に1か所で答えられます。** 質問はプロジェクトに属し、タスクは自分が待っている質問を参照します。レーンの上の**未回答の質問**の帯に、開いている質問がすべて並びます。質問に順に答え、最後に**まとめて送る**で一度に送ります。ボードでもスマートフォンでも同じです。会話中のエージェントはチャットでも同じ質問をし、ボードとチャットのうち先に届いた答えが有効になります。
- **タスクを動かしても質問は取り下げられません。** 質問は、答えるかエージェントが取り下げるまで開いたままです。
- **ボードが自動で起動します。** 待っている質問、`wait`、Hookなど、サーバーが要るコマンドは、サーバーを裏で起動し、プロジェクトのボードをブラウザーで1回開きます。使われないまま30分たつと止まります。`agboard open` で、今のプロジェクトのボードを開けます。

### 不具合修正

- このPCに保存したngrokのトークンを使ってよいかをOSが確認している間（更新した後など）も、ボードが応答し続けるようになりました。確認の答えを待つのは、保存したトークンでの接続と、トークンの削除だけです。
- エージェントが画像を読んだり、出力の長いコマンドを実行したりしたあとも、Hookがボードの進行表を渡すようになりました。これまでは`hook_input_too_large`を返し、エージェントがボードを読み直す必要がありました。

### 互換性に影響する変更

- `agboard connect` はなくなりました。SkillとHookは、`agboard setup` がプラグインとして入れます。
- `agboard update` はプラグインを更新するコマンドになりました。プラグインが入っていないエージェントは飛ばし、`agboard setup` の実行を案内します。
- `agboard state <id> pending` はなくなりました。エージェントは `agboard qa ask` で質問し、`agboard qa wait` で答えを待ちます。
- 以前の版で開いたままの質問は引き継がれません。更新すると、その質問はタスクから消えます。

### 必要な更新操作

更新する前に、ボードの開いている質問に答えておいてください。

そのあと、コマンドを更新してプラグインを入れます。

```sh
brew upgrade fooqoo/tap/agboard
agboard setup
```

今回はまだプラグインが入っていないので、`agboard update` では足りません。一度 `agboard setup` を実行してください。次の版からは `agboard update` だけで済みます。

`agboard connect` で入れたSkillとHookは、自動では消えません。Hookが二重に動かないよう、`agent-board` のSkillフォルダーと、エージェントの設定にある `agboard hook` を実行するHookの項目を消してください。

## v1.0.0

Agent Boardは、Claude CodeやCodexとタスク・進捗・判断を共有するローカルの作業ボードです。初回の公開版では、macOSへのHomebrewによる導入と、案内に沿ったエージェント連携の設定を提供します。

この版には2つの提供段階が混在します。ボード、タスク、判断依頼、エピック、エージェントが使うCLI、`connect`と`update`、初回の案内は一般提供（GA）です。ドキュメント、タスクの受け取り、モバイルモニターはパブリックプレビューで、今後の版で動作が変わる可能性があります。各段階の意味と現在の制約は[機能の提供段階](./guide/feature-stages.md)をご覧ください。GAは、不具合がないことや、今後も変更しないことを約束するものではありません。

### 変更点

- **Homebrewで導入できます。** `brew install fooqoo/tap/agboard`で、Web UIを含む署名済みのビルド済みコマンドをインストールします。Agent Boardをソースからビルドする必要はありません。
- **エージェントと連携できます。** `agboard connect`が、設定するエージェントと配置先を尋ね、Claude Code・Codex・両方のSkillとHookを導入します。書き込む前にすべての変更を表示し、変更するファイルはバックアップし、あなたが編集した内容は上書きしません。
- **対象外のフォルダではHookが静かに終わります。** プロジェクトに紐付いていないフォルダでGlobal Hookが動いても、何も出力せずに正常終了し、エージェントは作業を続けられます。
- **SkillとHookを更新できます。** `agboard update`が、導入済みのSkillとHookをコマンドの版にそろえます。通常のコマンドも、導入済みのものが古いときは知らせます。
- **スマートフォンから回答できます。** モバイルモニターは、ngrokとパスコードで接続します。（パブリックプレビュー）

macOS 15以降のApple SiliconまたはIntel Macが必要です。Agent Board本体はMITライセンスです。同梱する第三者のコンポーネントには、`THIRD_PARTY_NOTICES.txt`に記載したそれぞれのライセンスが適用されます。

### 不具合修正

初回の公開版のため、以前の公開版に対する修正はありません。

### 互換性に影響する変更

ありません。壊れる対象となる以前の公開版がありません。

### 必要な更新操作

新規に導入する場合、更新の操作は不要です。

```sh
brew install fooqoo/tap/agboard
cd my-project
agboard project create "My project"
agboard connect
agboard serve
```

以降の版では、`brew upgrade fooqoo/tap/agboard`でコマンドを更新します。SkillやHookが変わる版では、`agboard update`を実行し、変更されたHookをエージェントの`/hooks`で確認してください。詳しくは[インストールと起動](./guide/getting-started.md)と[エージェントとの連携](./guide/delegate/agents.md)をご覧ください。
