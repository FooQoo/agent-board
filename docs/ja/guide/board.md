# ボード

## カードと進捗

1. ヘッダーでプロジェクトを選び、**カード追加**を選びます。
2. タイトルを入力し、担当にAIかユーザーを選び、本文を書きます。下部の受け入れ条件の欄を開くと、完了条件を追加できます。
3. カードを選ぶと、**本文**・**受入条件**・**履歴**・**エピック**のタブが開きます。受入条件のタブには、カード自身の条件だけが並びます。カードを編集したりエピックに割り当てたりするには、**下書きにする**を選んでからエディターを開きます。別の列へ移すには、カードをドラッグして理由を確認します。

![カード自身の条件を表示した、受入条件タブのカード詳細](../../images/guide/card-detail.ja.png){.screenshot}

右側のパネルに選択したカードが表示されます。受入条件のタブには、カード自身の条件だけが進捗バーつきで並びます。エピックの参考条件は計画本文に書きます。

カードの担当は作成後に変更できません。列は作業の進み具合を表します。

| 列 | 意味 |
| --- | --- |
| 未着手(Todo) | まだ始めていない作業。 |
| 進行中(Doing) | 作業中。AIが担当するカードにはエージェントの状態も表示されます。 |
| 完了(Done) | 完了した作業。 |

進行中のAI担当カードには、**未稼働**・**稼働中**・**待機中**のいずれかが表示されます。エージェントが着手前に質問した場合は、未着手のカードも待機中になります。ユーザー担当のカードと完了のカードは、常に未稼働です。稼働中はエージェントが作業していること、待機中は返事が必要なことを表します。列を移すとエージェントの状態は未稼働に戻り、未回答の質問は取り下げられます。変更とその理由は履歴に残ります。

待機中の質問への回答は[判断依頼](./decisions)を参照してください。

## 下書き

エージェントに触れさせたくないカードを作るときは、**下書き**のチェックボックスを使います。既存のカードでは、詳細パネルで**下書きにする**を選び、本文を編集して保存し、エージェントに任せる準備ができたら**確定する**を選びます。カードエディターで保存しても下書きの状態は変わりません。エディターには下書きのチェックボックスがありません。下書きのカードは、`TASK.md`も含めてエージェントからは読み取り専用です。

## アーカイブ

カードは個別にアーカイブできます。完了の列で**完了カードをアーカイブ**を選ぶと、複数のカードをまとめてアーカイブできます。ヘッダーの**アーカイブ**を開くと、アーカイブ済みのカードを確認し、復元し、完全に削除できます。ブラウザでの完全削除はアーカイブから行います。

![5件のアーカイブ済みカードと「ボードに戻る」ボタンを表示したアーカイブ画面](../../images/guide/archive.ja.png){.screenshot}

アーカイブ画面には、アーカイブ済みのカードがID、タイトル、日付、担当とともに並びます。カードを選ぶと詳細を確認でき、元の列へ復元することも、完全に削除することもできます。

## 言語とテーマ

**設定**を開くと、英語か日本語と、24のテーマ(12色それぞれのライトとダーク)の1つを選べます。変更はすぐに適用され、ブラウザに保存されます。初期設定は英語とライトブルーで、ブラウザやOSの設定には従いません。カードの内容は翻訳されません。CLIのヘルプとエラー、API/JSONの値は英語のままです。

![言語の切り替えと、ライトとダークのカラーテーマの選択肢を表示した設定ダイアログ](../../images/guide/settings.ja.png){.screenshot}

ダイアログには、言語の切り替えと、ライト12色・ダーク12色のテーマが並びます。

![ダークテーマのボード](../../images/guide/board-dark.ja.png){.screenshot}

ダークテーマを選ぶと、同じボードがこのように表示されます。
