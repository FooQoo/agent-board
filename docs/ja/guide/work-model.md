# 仕事のモデル

Agent Boardは、画面ではなく、仕事のモデルを中心に作られています。このモデルがあるので、エージェントは、次に何をするか、いつ終わりか、いつあなたに聞くか、何を残すかを判断できます。ボード、`agboard`コマンド、ファイルは、どれも同じモデルへの入口です。このページは一度読んでください。ほかのページは、ここで説明する内容を前提にしています。

## 要素

| 要素 | 内容 | エージェントにとっての役割 |
| --- | --- | --- |
| **プロジェクト** | 作業フォルダに結びつく一つのボード。エピック・タスク・質問・履歴を持ちます。 | 作業の範囲を一つに定めます。プロジェクトが見つからないときは、推測せずに止まって知らせます。 |
| **エピック** | 目的と、タスクの進行順。 | 次にやることを決めます。 |
| **タスク** | 単独でレビューできる一つの作業。担当は**AI**か**ユーザー**で、作成時に決まり、変えられません。 | 作業の単位と、誰がやるかを決めます。 |
| **受入条件** | 各タスクにあり、何を満たせば終わりかを示すチェックリスト。 | 終わりを決めます。 |
| **質問** | エージェントがあなたに求める判断。多くは選択肢と推奨を添えます。 | エージェントを止めて待たせます。 |
| **開始の承認** | 計画を始めてよいかを尋ねる質問。 | あなたが承認するまで、計画のタスクを止めます。 |
| **履歴** | 起きたことを時系列に並べたもの。各項目は日時と理由を持ちます。 | 新しいセッションや別のエージェントが、前の続きから始められるようにします。 |
| **下書き** | まだ書いている途中のタスクやエピック。 | エージェントが触れないようにします。 |
| **アーカイブ** | 片付けたタスク。 | 書き込みをすべて止めます。 |

タスクには、計画・結果・リンクを書く自由なMarkdownの**タイトル**と**本文**もあります。タスクは最大で一つのエピックに所属します。エピックの進行順と、列の中での並びは別のものです。

すべては、あなたのマシンのフォルダ（既定では`~/.agent-board/`）に通常のファイルとして保存されます。ブラウザ、`agboard`コマンド、エージェントが同じファイルを読み書きします。[データとバックアップ](./operations/data)を参照してください。

## 状態

タスクは三つの**列**のどれかにあります。**未着手**（Todo）はまだ始めていない作業、**進行中**（Doing）は作業中、**完了**（Done）は終わった作業です。AI担当のタスクには、エージェントが何をしているかを示す**未稼働**（Idle）・**稼働中**（Running）・**待機中**（Pending）も表示されます。

| 担当 | 未着手 | 進行中 | 完了 |
| --- | --- | --- | --- |
| **AI** | 未稼働、待機中 | 未稼働、稼働中、待機中 | 未稼働 |
| **ユーザー** | 未稼働 | 未稼働 | 未稼働 |

- **未稼働**は、いまエージェントがそのタスクに取り組んでいないことを表します。
- **稼働中**は、エージェントが最後に報告した状態で、進行中だけにあります。実際に動いているかを確かめたものではありません。エージェントが異常終了すると、誰かが変えるまで、タスクは稼働中のままです。別の列に移すと未稼働に戻ります。
- **待機中**は、誰も設定できません。質問から導かれます。AI担当のタスクが未着手か進行中にあり、未回答の質問を参照している間は待機中です。計画に属するタスクは、計画の質問に答えたあとも、開始を承認するまで待機中のままです。承認ではない選択肢を選んだときは、承認をタスクから外すまで待機中が続きます。
- あなたが担当のタスクは、常に未稼働です。

## 質問と判断依頼 {#decisions}

エージェントはあなたの判断なしには進めないとき、**判断依頼**を出します。質問と、たいていは選択肢と推奨が付きます。質問はプロジェクトに属し、それを参照するタスクが**待機中**になって質問を表示します。選択肢を選ぶか、メモを書くか、両方を行って回答すると、回答は履歴に残り、エージェントはそれを読んでから作業を再開します。質問は、回答されるまで未回答のまま残ります。

回答は、ボード、スマホ、チャット、CLIのどこからでもできます。最初に記録された回答が有効です。[判断依頼](./delegate/decisions)を参照してください。

## 受入条件と自動完了

受入条件は、作業を始める前に書きます。エージェントは、検証が済んだ条件だけを達成済みにします。AI担当のタスクのすべての条件が達成で、あなたを待つものがなくなると、サーバーが動いている間、タスクは自動で**完了**に移り、その理由が履歴に残ります。条件のないタスク、あなたが担当のタスク、下書き、待機中のタスクは、自動では完了しません。ファイルの形式は[Markdownファイルの形式](./reference/file-format)に説明があります。

## エピックと作業の順序

エピックは、タスクをまとめて管理する単位です。名前・色・Markdownで書いた詳細・タスクの順序を持ちます。エージェントは順序を読んで、次にやることを選びます。[エピックと進行表](./watch/epics)を参照してください。

## 履歴

タスクの移動や状態変更、質問と回答、チェックした条件、エージェントが追記した進捗のメモが、履歴に記録されます。各項目は日時と理由で構成され、履歴は記録のように読めます。エージェントは、やったことと確かめたことも書き残します。**履歴**タブでは新しい順に確認できます。

## モデルが保証すること

次の決まりは、エージェントの善意ではなく、Agent Boardそのものが守ります。

- **タスクの担当は変わりません。** 担当は作成時に決まります。
- **有効な状態だけが存在します。** 組み合わせられない列と稼働状態は拒まれ、待機中を手で設定することもできません。
- **回答がなければ、エージェントは待ちます。** 未回答の質問を参照するタスクは待機中になり、エージェントは稼働中にできません。質問を出すと、稼働中のタスクは同時に未稼働へ戻ります。
- **あなたの承認なしに計画は始まりません。** 計画のタスクは、承認された開始の承認があるまで待ち、承認ではない答えが返ったときも待ち続けます。
- **あなたの回答は、あなたの回答として一度だけ記録されます。** 最初の回答が有効で、上書きされません。質問・回答・それを参照するタスクの履歴は、まとめて保存されます。
- **完了は、条件を満たしたことを意味します。** AI担当のタスクが完了するには、受入条件が1つ以上あり、すべて達成され、未回答の質問がないことが必要です。移すときには、最新のファイルで確かめ直し、理由を履歴に残します。これは自動の完了が確かめる条件です。エージェントが手で完了に移すときも、すべての条件の達成と未回答の質問がないことが必要ですが、受入条件のないタスクは拒まれません（[まだエージェント頼みのところ](#relies-on-agent)を参照）。
- **終わった仕事は、終わったままです。** エージェントは完了したタスクを変更できません。あなたが列を戻せば、再び作業できます。条件のチェックを外しても、完了したタスクは自動では戻りません。
- **下書きとアーカイブは柵で守られます。** エージェントはあなたの下書きに触れられず、アーカイブしたタスクには誰も書き込めません。
- **すべてに理由が残ります。** 列・状態・質問・回答・条件のチェックの変更は履歴に記録され、形が崩れた履歴は推測せずに拒まれます。タスクと質問の番号は使い回されません。
- **計画を書き換えても、記録は残ります。** タスクの本文と条件を置き換えても、履歴と質問への参照は保たれます。

## 介入するところ

関わり方は二つあり、どちらも同じモデルを通ります。

| 関わり方 | 起きること | あなたがすること |
| --- | --- | --- |
| **聞かれたら答える**（Human-in-the-Loop） | エージェントが、自分では決められない判断のために止まって待ちます。 | 計画の質問に答える、開始を承認する、作業中の質問に答える。 |
| **見守って介入する**（Human-on-the-Loop） | あなたが見ている間も、エージェントは動き続けます。次にボードを読むときに、変更に従います。 | カードを戻す、または完了にする、条件にチェックを付ける、本文や条件を書き換える、アーカイブする、削除する。 |

エージェントがあなたを呼ぶのは、意図が分からない、好みで決まる、取り返しがつかない、頼まれた範囲を超えて広がる、の4つの場合だけです。この線引きはエージェントのSkillにあり、モデルは、エージェントが質問したら止まることを守ります。[エージェントとの連携](./delegate/agents)を参照してください。

## まだエージェント頼みのところ {#relies-on-agent}

モデルがまだ強制していないことがあります。エージェントがSkillに従うことに頼っているので、どこにあるかを知っておいてください。

- **質問の取り下げ。** 質問を取り下げるコマンドは、実行した人を確かめません。エージェントが質問を取り下げて、待ちを解けてしまいます。これは、エージェントがしないことに頼っています。
- **条件のないタスク。** エージェントは、受入条件のないタスクを手で完了に移せます。自動の完了では起きません。
- **誰が答えたか。** モデルは、実際に誰が回答を入力したかを確かめません。チャットで返答したときは、エージェントがあなたの言葉をボードに記録します。
- **ファイルの直接編集。** `TASK.md`を手で書き換えると、柵と履歴の自動記録を通りません。ボードかCLIを使ってください。
- **稼働中。** 稼働中は自己申告なので、エージェントが止まっていても、動いているように見えることがあります。
- **自動の完了にはサーバーが必要。** `agboard serve`が動いている間だけ起きるので、終わったタスクがサーバーの起動まで進行中に残ることがあります。
- **あなたが担当のタスク。** 記録はされますが、検証はされません。
- **エピック。** エピックが終わったかどうかはモデルが管理せず、完了の条件は本文に書きます。
