# 機能の提供段階

Agent Board v1.0.0の機能は、一般提供（GA）とパブリックプレビューのどちらかの段階にあります。このページでは、それぞれの段階の意味、各段階の機能、プレビューの機能を使う前に知っておきたい制約をまとめます。v1.0.0にはどちらの段階も含まれていて、すべての機能がGAというわけではありません。

## 段階の意味

| 段階 | 意味 | 意味しないこと |
| --- | --- | --- |
| 一般提供（GA） | このガイドの説明どおりに動作し、当面はその仕様で運用していく機能です。今後の変更は、機能を足す方向を想定しています。 | 不具合がないことを意味しません。互換性やサポートを無期限に保証するものでもありません。 |
| パブリックプレビュー | 試していただくために公開している機能です。今後の版で動作や仕様が変わる可能性があり、後述の制約があります。 | 機能の利用を制限したり、ライセンスを変えたりするものではありません。 |

段階は、その機能が今後どれだけ変わりうるかを表します。どれだけ入念に試験したかを表すものではありません。よく使われる機能が、それだけでGAになるわけでもありません。

## 製品内の表示

パブリックプレビューの機能は、使う前に次の注意を表示します。

> この機能はパブリックプレビューです。仕様や動作が変更される可能性があります。現在の制約はドキュメントをご確認ください。

表示される場所は次のとおりです。

| 機能 | 表示される場所 |
| --- | --- |
| [ドキュメント](#docs) | 「ドキュメント」ダイアログの見出しに「パブリックプレビュー」のバッジが付き、その下に注意文とこのページへのリンクが出ます。 |
| [モバイルモニター](#mobile-monitor) | パソコンの「モバイル接続」ダイアログにバッジが出ます。接続する前は、注意文とこのページへのリンクも出ます。スマートフォンのモニターには出ません。 |
| [タスクの受け取り](#listen) | 画面はありません。このページとエージェントのSkillで説明します。 |

GAの機能には、この表示はありません。

## パブリックプレビューの機能

### ドキュメント {#docs}

「ドキュメント」ダイアログで、プロジェクトの`docs/`フォルダにあるファイルを一覧して読めます。機能は今も変わり続けています。

- **対応範囲:** パソコンのブラウザのボード。モバイルモニターにはドキュメントを表示しません。
- **制約:** MarkdownとMDXのファイルは2 MiBまで、画像は10 MiBまでです。
- **ガイド:** [プロジェクトのドキュメント](./use/docs)

### タスクの受け取り {#listen}

`agboard wait --until task`で、開いているClaude CodeやCodexの1つのセッションが、AIのタスクを続けて受け取れます。

- **対応範囲:** Claude CodeとCodex。エージェントのSkillにある手順に従います。
- **制約:** 複数のセッションが同じタスクを受け取らないことは保証しません。連続して実行する操作は、人がエージェントのセッションで始めます。
- **ガイド:** [次のタスクを待つ](./automation/agents#listen-for-the-next-task)

### モバイルモニター {#mobile-monitor}

モバイルモニターは、スマートフォンでボードを確認し、エージェントの質問に答えるための画面です。

- **対応範囲:** スマートフォンのブラウザ。ngrokを経由します。
- **制約:** ngrokに依存し、HTTPSはngrokで終端されます。パソコンが起動していて、`agboard serve`が動いている間だけ使えます。接続の方式は今後変わる可能性があります。
- **ガイド:** [モバイルモニター](./operations/mobile-monitor)
