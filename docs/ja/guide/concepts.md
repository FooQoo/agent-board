# 基本の考え方

ボードを使ううえで基本となる、プロジェクト・タスク・列・エージェントの状態などを説明します。各操作のガイドも、これらの概念を前提にしています。

## プロジェクト

プロジェクトは一つのボードです。タスク・エピック・履歴はプロジェクトごとに独立しています。ブラウザではヘッダーでプロジェクトを選び、コマンドラインでは`--project NAME`で指定します。

## タスク

タスクは一つの作業を表し、次の情報を持ちます。

- **タイトル**と**本文**（自由なMarkdown。計画、結果、証跡へのリンク）。
- **担当**: エージェントが行う作業は**AI**、あなたが行う作業は**ユーザー**。担当はタスクの作成時に決まり、変えられません。
- **受入条件**: 作業の完了を判断するためのチェックリスト。
- **履歴**: 何が起きたかを時系列に並べたもの。各項目は日時と理由を持ちます。

## 列

タスクは三つの列のどれかにあります。

| 列 | 意味 |
| --- | --- |
| **未着手（Todo）** | まだ始めていない作業。 |
| **進行中（Doing）** | 作業中。 |
| **完了（Done）** | 完了した作業。 |

## エージェントの状態

AI担当のタスクには、エージェントが何をしているかも表示されます。

| 状態 | 意味 | 設定できる列 |
| --- | --- | --- |
| **未稼働（Idle）** | エージェントが作業していない。 | すべての列。ユーザー担当のタスクと完了したタスクは常に未稼働。 |
| **稼働中（Running）** | エージェントが作業している。 | 進行中だけ。 |
| **待機中（Pending）** | エージェントがあなたの回答を待っている。 | 未着手と進行中。 |

稼働中は、エージェントが最後に報告した状態で、エージェントが実際に動いていることを保証するものではありません。エージェントが異常終了すると、誰かが変えるまで、タスクは稼働中のままです。タスクを別の列に移すと未稼働に戻り、未回答の質問は取り下げられます。

## 判断依頼

エージェントはユーザーの判断が必要になると、質問と選択肢を添えた**判断依頼**を出します。タスクは**待機中**になり、回答欄が表示されます。選択肢を選ぶか、メモを入力して回答してください。両方を入力することもできます。回答は履歴に残り、エージェントはその内容を読んでから作業を再開します。質問は、回答されるまで未回答のまま残ります。[判断依頼](./use/decisions)を参照してください。

## 受入条件と自動完了

受入条件は、各タスクにあるチェックリストです。エージェントは、検証が済んだ条件を達成済みにします。AI担当のタスクのすべての条件が達成になると、タスクは自動で**完了**に移ります（サーバーが動いている間）。条件のないタスク、あなたが担当のタスク、下書き、待機中のタスクは、自動では完了しません。ファイルの形式は[Markdownファイルの形式](./automation/file-format)に説明があります。

## エピック

エピックは、タスクを一つの計画のもとにまとめます。名前・色・Markdownで書いた計画・タスクの順序を持ちます。タスクは、最大で一つのエピックに所属します。エージェントは、順序を読んで、次にやることを選びます。[エピックと進行表](./use/epics)を参照してください。

## 下書き

下書きは、あなたがまだ書いているタスクです。エージェントは読み取り専用として扱うので、書きかけのものを変えることはありません。準備ができたら確定します。[下書き](./use/board#下書き)を参照してください。

## 履歴

タスクの移動や状態変更、質問と回答は、履歴に自動で記録されます。エージェントが追記した進捗のメモも同じ履歴に並びます。各項目は日時と理由で構成され、**履歴**タブでは新しい順に確認できます。

## データの置き場所

すべては、あなたのマシンのフォルダ（既定では`~/.agent-board/`）に通常のファイルとして保存されます。ブラウザ、`agboard`コマンド、エージェントが、同じファイルを読み書きします。[データとバックアップ](./operations/data)を参照してください。
